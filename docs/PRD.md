# XPrice PRD

**产品名称：** XPrice  
**一句话：** 把 X Premium 官方各国标价，变成一张能比、能换算、能看懂的全球价格图。  
**文档版本：** v0.1  
**日期：** 2026-08-18  
**状态：** 待评审（规划稿，尚未开发）  
**数据基准：** [X Help · About X Premium](https://help.x.com/en/using-x/x-premium#tbpricing-bycountry)（页面标注 2026-05-06）+ 汇率 2026-08-18

---

## 1. 背景与问题

X 官方帮助页底部有一张约 **190 个国家/地区** 的 Web 订阅价目表，覆盖 Basic / Premium / Premium+，以及月付 / 年付。这张表对「比价」几乎不可用：

| 官方表的现状 | 用户真正想知道的 |
| --- | --- |
| 本币标价，土耳其 ₺150、英国 £8、美国 $8 无法直接比 | 「换算成美元/人民币，哪里更贵」 |
| 约 130 国直接套用美国美元价，看起来像 190 条独立价格 | 「真正做了本地化定价的市场有哪些」 |
| 只有 Web 价，不含税、不含 iOS/Android 渠道溢价 | 「网页订和 App 内购差多少」 |
| 没有地图、没有排序、没有年付折扣 | 「一眼看出贵贱带，年付能省多少」 |
| 价格会改（2025-02 Premium+ 从约 $22 提到 $40），页面却是静态长表 | 「这份数据是哪天的，变过没有」 |

市场上已有 OpenTheRank、AppPriceWatch 等站点，但它们主打 **App Store 区域价 + 换区/礼品卡路径**。XPrice 不做这条：只做公开标价的可视化与换算，帮助用户理解全球定价分布。

---

## 2. 产品定位

**XPrice 是一个只读的全球订阅价格观测站，不是下单站，也不是换区教程。**

- **是：** 官方 Web 标价 → 统一货币 → 地图热力 + 排行 + 国家详情。
- **不是：** VPN / 虚假账单地址 / 礼品卡换区 / 代付代订。
- **品牌关系：** 独立第三方工具。页脚必须写「非 X Corp. 关联产品，价格以官方结账页为准」。

### 核心价值主张

> 用一张世界地图，回答三个问题：X Premium 在各国标多少、换成我的货币是多少、年和月怎么选更划算。

### 成功标准（MVP 上线后 30 天）

1. 用户 **60 秒内** 能回答「Premium 月付，换算成人民币，最便宜和最贵的 5 个市场是谁」。
2. 任意国家详情页能同时看到：本币价、USD、CNY、相对美国溢价/折价、年付折扣。
3. 数据来源、采集日期、汇率日期在首页可见，不靠用户翻「关于」。

## 3. 目标用户

| 角色 | 诉求 | 优先级 |
| --- | --- | --- |
| 普通订阅决策者 | 自己所在市场贵不贵，Web 和 App 差多少，年付值不值 | P0 |
| 创作者 / 运营 | 了解蓝标、广告分成门槛在不同市场的成本 | P0 |
| 旅行者 / 多地区用户 | 对比常住地 vs 目的地的官方标价（不做换区指导） | P1 |
| 媒体 / 研究者 | 引用「全球价差、本地化市场名单、Premium+ 涨价后格局」 | P1 |

**语言：** 首发简体中文，英文为 P1。默认展示货币：CNY，可切 USD / 本币。

**地理现实：** 官方表 **没有中国大陆**。香港（HKD）、台湾（TWD）有独立标价。产品必须把大陆标成「官方未列出」，不要伪造一条 CNY 订阅价。

## 4. 明确不做（Non-goals）

1. 教用户如何改区、用礼品卡、用虚拟地址购买更低价订阅。
2. 代扣、代订、账号共享、支付跳转进 X 结账（可外链到官方帮助页，不可伪装成官方）。
3. 覆盖 Verified Organizations / Premium Business 企业套餐（个人三档即可）。
4. 承诺「实时同步官方结账价」。MVP 以帮助中心公开表为准，并标明可能与结账页不一致（官方自己也出现过帮助页与收银台数字不同）。
5. 首发不做用户账号、评论、UGC 报错社区。

## 5. 市场洞察（用于产品设计，不是页面文案堆砌）

以下为 **Web 官方月付 Premium**，按 2026-08-18 汇率折美元。汇率会变，产品必须以「本币官方价 × 当日汇率」计算，下表只用于说明价差结构。

### 5.1 真正便宜的本地化市场（Premium 月付）

| 市场 | 官方本币 | 约合 USD | vs 美国 $8 |
| --- | --- | --- | --- |
| 尼日利亚 | ₦3,650 | ~$2.68 | −66% |
| 土耳其 | ₺150 | ~$3.13 | −61% |
| 埃及 | EGP 244.99 | ~$4.88 | −39% |
| 日本 | ¥980 | ~$6.15 | −23% |
| 印尼 | Rp120,000 | ~$6.73 | −16% |
| 印度 | ₹650 | ~$6.79 | −15% |
| 孟加拉 | ৳850 | ~$6.93 | −13% |

### 5.2 偏贵的市场

| 市场 | 官方本币 | 约合 USD | vs 美国 $8 |
| --- | --- | --- | --- |
| 哥伦比亚 | COP 38,500 | ~$12.27 | +53% |
| 英国 | £8 | ~$10.84 | +36% |
| 以色列 | ₪29 | ~$9.78 | +22% |
| 波兰 | 36 zł | ~$9.67 | +21% |
| 欧元区多数 | €8 | ~$9.27 | +16% |
| 澳大利亚 | A$13 | ~$9.24 | +16% |

### 5.3 产品必须处理的数据特征

1. **价格带，不是 190 个独立价。** 大量国家直接用美国美元价（$3 / $8 / $40）；欧元区多数共用 €3 / €8 / €38；英国+直布罗陀共用英镑；瑞士+列支敦士登共用法郎。地图应渲染「价区」，表格默认折叠「美元篮子」。
2. **三档价差结构不同。** Premium 最便宜可以到美国的约 1/3；Premium+ 在土耳其约 $30、美国 $40、比利时月付却是 **€46**（年付仍是 €377，和其他欧元区年付一样）——这是官方表异常点，详情里要标出来，不要静默平均掉。
3. **渠道差。** 公开资料里 Web 通常比 iOS/Android 内购便宜约 20–30%（美国 Premium 约 $8 Web vs ~$11 App）。MVP 只保证 Web；P1 再叠加 IAP。
4. **年付折扣大约一成。** 美国 Premium：$8×12=$96 vs 年付 $84，约 12.5%。每个国家都要算「等效月费」和「省下的金额」，不要只展示年价数字。
5. **税和支付手续费未计入。** 官方原文：*Prices may vary by location, applicable taxes, and your payment method fees.* 所有价格旁常驻这句释义。

美国 Web 三档锚点（帮助中心）：

| 档位 | 月付 | 年付 | 年付等效月费 | 年付折扣 |
| --- | --- | --- | --- | --- |
| Basic | $3 | $32 | $2.67 | ~11% |
| Premium | $8 | $84 | $7.00 | ~12.5% |
| Premium+ | $40 | $395 | $32.92 | ~18% |

## 7. 产品原则

1. **本币是事实，美元/人民币是视图。** 排序、地图着色用折算值；卡片第一行永远是官方本币。
2. **先看分布，再看名单。** 首页英雄是地图，不是 190 行表格。
3. **可信比炫技重要。** 来源链接、抓取日期、汇率日期、税未含，全部露在主界面。
4. **不帮用户违规省钱。** 发现「最便宜」之后，下一步是「去官方页看自己市场的价」，不是「怎么买到土耳其价」。
5. **一个主操作。** 进入站点后，默认已选：档位=Premium、周期=月付、货币=CNY。

## 9. 功能需求

### P0 — MVP（建议 1–2 周可上线静态站）

| ID | 功能 | 验收标准 |
| --- | --- | --- |
| F1 | 全球热力地图 | 按当前档位+周期，用折算后的展示货币着色；无数据（如中国大陆）用独立灰色，不进色阶 |
| F2 | 档位 / 周期切换 | Basic、Premium、Premium+ × 月付、年付；切换后地图、榜单、表格同步 |
| F3 | 展示货币 | 至少 CNY、USD；国家卡同时显示本币 |
| F4 | 搜索 | 中英文国名、ISO 代码；回车打开国家详情 |
| F5 | 悬停 / 点击 | 悬停：本币 + 折算价；点击：进入国家详情 |
| F6 | 国家详情 | 六价齐全；USD、CNY；vs 美国%；全球排名（仅在「有本地化标价」集合内排，美元篮子可标「与美国同价」而不占 130 个并列第 N） |
| F7 | 双榜 | 最便宜 8、最贵 8；排除重复美元篮子，只保留代表国+「另有 N 国同价」 |
| F8 | 完整表 | 排序、筛选「仅本地化货币」；默认按折算价升序 |
| F9 | 年付解读 | 展示「年付等效月费」和「相对 12 个月付节省」 |
| F10 | 数据可信区 | 来源 URL、帮助页日期、汇率日期、税/手续费未含 |
| F11 | 免责与红线 | 页脚免责；全站无换区/VPN/礼品卡引导 |
| F12 | 响应式 | 手机先看洞察条+榜单，地图可横滑或简化；桌面地图为主 |

### P1

- Web vs iOS vs Android 三列（需第二数据源，标明「非官方帮助表」）。
- 两国/三国对比。
- 英文界面。
- 价格变更时间线（每次抓取快照）。
- PPP（购买力平价）视图：回答「对当地人贵不贵」，与「折美元贵不贵」分开，避免混在同一个色阶。
- 汇率手动刷新 / 显示 24h 变化对排名的影响（土耳其、尼日利亚等对汇率极敏感）。

### P2

- 邮件/RSS：某国或全球价差变动通知。
- Premium Business / Organizations。
- 嵌入用的精简地图 widget。

## 10. 关键用户路径

### 路径 A：我该不该开 Premium？

1. 落地即见默认：Premium × 月付 × CNY。
2. 搜索「日本」或点地图。
3. 看到 ¥980 / 约 ¥44 人民币量级的折算（示例，以实时汇率为准）、年付折扣、相对美国 −23%。
4. 点「查看官方说明」离开。

### 路径 B：全球到底差多少？

1. 看洞察条：「最便宜尼日利亚，最贵哥伦比亚，约 4.6 倍」。
2. 扫地图色带：西非/土耳其偏冷色，英国/哥伦比亚偏暖色，大片美元篮子同色。
3. 打开完整表，打开「仅本地化定价」。

### 路径 C：年付划不划算？

1. 切到年付，等效月费下降，色阶微调。
2. 国家页写清：美国 Premium 年付相当于 $7/月，比月付少约 $12/年。

## 12. 数据设计

### 12.1 官方价（静态事实）

每行一个国家：

- `iso2` / `iso3` / 中英文名
- `currency`
- `pricingGroup`：`localized` | `usd_basket` | `eur_basket` | `gbp_basket` | `chf_basket`
- 六个金额：`basic.month` `basic.year` `premium.month` `premium.year` `plus.month` `plus.year`
- `source`：帮助中心 URL
- `sourceCapturedAt`：抓取日期
- `notes`：如比利时 Premium+ 月付 €46 与年付 €377 和其他欧元区不一致

约 **55 个本地化货币市场** 需要单独维护；其余归入篮子，地图上合并渲染。

中国大陆：`availability = unpublished`，不生成假价格。

### 12.2 汇率（易变）

构建时或客户端拉取 USD 中间价，再换 CNY。展示必须带汇率日期。尼日利亚、土耳其、埃及等排名会随汇率跳动，UI 要让用户知道「变的是汇率，不一定是 X 改了价」。

### 12.3 派生字段（不要存死）

- 折 USD / CNY
- vs 美国百分比
- 年付等效月费、节省额与节省比例
- 在 `localized` 集合中的名次

### 12.4 更新策略

| 层 | 频率 | 方式 |
| --- | --- | --- |
| 官方本币价 | 每周检查，变了就更 | 解析帮助中心表格；失败则人工对照 |
| 汇率 | 每日 | 公开汇率 API |
| IAP（P1） | 每周 | 独立数据源，禁止和官方 Web 表混写成同一列 |

解析失败不能静默沿用过期价：首页出现「价格表未刷新，仍显示 xxxx-xx-xx」。

## 13. 技术方案（建议，非实现承诺）

适合做成 **静态生成站点**：价格不是秒级数据，SEO 和托管成本都友好。

- 框架：Next.js（App Router）+ TypeScript
- 地图：MapLibre GL 或等效矢量地图，国家边界用 ISO 码绑定
- 数据：仓库内 JSON/TS 模块 + 每日汇率
- 抓取：GitHub Action 定时拉帮助页，diff 后开 PR（表格结构一变就要能失败告警）
- 部署：Vercel / Cloudflare Pages
- 分析：仅匿名页面统计，不上用户账号

不需要首发后端。P1 价格历史再用简单存储（SQLite 或对象存储快照）。

## 14. 合规与风险

| 风险 | 处理 |
| --- | --- |
| 商标 | 用 XPrice 自有品牌；不使用 X 官方 Logo 作为站标；文案写「X Premium 为 X Corp. 产品」 |
| 数据准确性 | 帮助页 ≠ 收银台；税、州税、支付渠道费未含。每屏可见 |
| 被当成换区站 | 禁止教程、联盟链接、虚拟地址 CTA。榜单文案用「标价最低的市场」，不用「最便宜入手地」 |
| 汇率误导 | 高波动货币在详情标注「折算价随汇率变化」 |
| 抓取中断 | 帮助页 403 常见，需备用读取方式 + 人工更新预案 |
| 官方改价不同步 | Premium+ 有过一周内帮助页、注册页、结账页三个数字的情况。产品只声称「帮助中心公开表」 |

## 17. 开放问题（评审时拍板）

1. **首发范围：** 只上 `localized` 约 55 国，还是 190 国全画（美元篮子合并着色）？建议全画，但表格默认藏篮子。
2. **中国大陆用户：** 地图灰显 + 文案「官方未列出」，是否额外说明「需在 X 可用地区订阅」？建议只陈述事实，不写操作建议。
3. **默认货币：** CNY 还是 USD？建议中文站 CNY。
4. **IAP 是否进入 MVP？** 建议否，避免第一版数据源不纯。
5. **域名与品牌：** XPrice 是否与 X 商标过于接近，是否改用更中性名（如 WorldPremiumPrices）？需上线前确认。
